## 核心思想

Fusion-v4 不调用 PBF、ESVA、ER，也不读取数据集名称或运行时真实焦点。它把事件相机扫焦定义为同一个物理不变量的中心估计：以真实焦点 `f` 为中心做时间反射，同时交换正负极性，事件场应近似保持不变。

每个采样区间的正负事件数为 `P_i、N_i`，持续时间为 `T_i`。先估计整条序列的正负极性增益 `g+、g-`，并计算校正率。等价的方差稳定表示为：

```text
Y+_i = 2 sqrt(g+ P_i T0/T_i + 3/8)
Y-_i = 2 sqrt(g- N_i T0/T_i + 3/8)
C_i  = (Y+_i + Y-_i)/sqrt(2)
D_i  = (Y+_i - Y-_i)/sqrt(2)
```

`C` 是总活动通道，`D` 是极性相位通道。真实焦点应满足：

```text
C(f-u) =  C(f+u)
D(f-u) = -D(f+u)
```

即总活动偶对称、极性相位奇对称。泊松计数方差、稳健过离散系数和 Huber 损失共同抑制暗噪声、热像素及突发异常。

## 一个损失与一个焦点评分

同一个奇偶模型在局部、介观和全局可观测支持上产生尺度条件似然 `H_s(f)=exp[-L_s(f)]`。尺度 `s` 是潜变量，不是三种对焦算法。当前序列的覆盖、峰曲率、过离散、极性充分性和合法小波长度只用于估计尺度可观测质量 `q_s`，并满足 `sum_s q_s=1`。

唯一物理损失为：

```text
L(f) = -log sum_s q_s H_s(f)
```

唯一焦点评分为：

```text
F(f) = exp[-L(f)] / sum_j exp[-L(j)]
f*   = argmax_f F(f)
```

峰值三个采样点使用抛物线插值得到亚采样焦点。`physical_parity_loss` 和 `focus_posterior` 已写入每条输出曲线。

r10 将 r9 的顺序式候选融合严格改写为一次尺度边缘似然。184 条公开序列相对 r9 的最大预测变化为 `0 µs`；因此 r10 的价值是物理模型、损失和评分的统一，不是用新规则追逐开发集精度。

## 不变性

| 变化来源 | 模型处理 |
|---|---|
| 正负阈值或传感器极性响应不同 | 序列级 `g+、g-` nuisance gain |
| 聚合时间不同 | 使用每个区间的 `T_i` 计算率与泊松方差 |
| 事件数量和对比度不同 | 泊松/准泊松标准化及单位信息似然 |
| 焦点结构宽度不同 | 对局部、介观、全局支持尺度边缘化 |
| 短序列不能支持全局尺度 | `dwt_max_level` 与长度充分性连续降低该尺度质量 |
| 单极性、全零、常数或纯噪声 | 可观测性门返回 `valid_focus=false`，不输出伪焦点 |

没有按 SYN、DAVIS、EVK4、EvHF、EAD 或自有数据切换公式，也没有根据真实值回退到某个基线。

## 数据聚合和可视化

- 公开数据：评分输入使用冻结审计的实际 1 ms bin。
- 自有数据：评分输入使用一个完整 ETL 状态区间，约 5 ms，并从 `02_etl_diopters.csv` 映射屈光度。
- 公开累计事件帧：以预测焦点为中心累计前后各 2.5 ms。
- 自有累计事件帧：累计预测焦点对应的完整 ETL 状态。
- 所有累计图使用完整传感器画布，固定 `s=1.5、alpha=0.65、linewidths=0`，不使用评分 ROI 裁剪。

每个序列输出事件率/焦点图、三尺度物理似然图、极性时序图、三张累计事件帧、完整曲线 CSV、方法结果和审计 JSON。部分图片文件名保留 `peof` 是为了兼容旧目录，图内标题和数据已经是 PPFM r10。

& $py '.\test_degenerate_inputs.py'

正式论文应锁定代码哈希后进行留一数据集验证或新增完全未参与设计的数据集。只有这种外层验证才能支持“跨数据集通用性”，不能继续以“让每个当前数据集第一”为目标反复修改尺度质量参数。
